 Sales Trend Analysis using SQL

 Objective
Analyze monthly revenue and order volume using SQL aggregation functions.

 Tools Used
- MySQL
- SQL Aggregation Functions

 Dataset Structure
Table: online_sales

Columns:
- order_id
- order_date
- amount
- product_id

SQL Concepts Used
- SUM()
- COUNT()
- GROUP BY
- ORDER BY
- YEAR() and MONTH() functions

 Analysis Performed
Calculated:
- Monthly total revenue
- Monthly total number of orders

This project demonstrates basic SQL data aggregation and trend analysis skills.
